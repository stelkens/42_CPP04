# CPP04 Subtype Polymorphism

This project introduces subtype polymorphism, abstract classes, and interfaces in C++.

## Exercises

- **ex00** — Create an `Animal` base class with derived classes `Dog` and `Cat`, demonstrating inheritance and polymorphism.
- **ex01** — Implement a `Brain` class and give `Dog` and `Cat` dynamically allocated brains to explore deep copies and memory management.
- **ex02** — Create an abstract `Animal` class that cannot be instantiated directly, using pure virtual functions.

## Topics

- Subtype polymorphism
- Inheritance
- Abstract classes
- Interfaces
- Virtual functions
- Deep copies and memory management
- Orthodox Canonical Form
